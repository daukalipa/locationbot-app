# Отметка прихода — мини-приложение

Страница для Telegram-бота учёта прихода на работу
([@almaty_clinic_time_bot](https://t.me/almaty_clinic_time_bot)).

Открывается кнопкой «📍 Отметить приход» внутри Telegram. Определяет
геолокацию через GPS телефона и передаёт её боту — расстояние до клиники
и опоздание считает уже сам бот.

Зачем нужна: геолокация браузера всегда возвращает погрешность вместе с
координатами, поэтому выбрать точку на карте пальцем, как это можно сделать
через «скрепка → Геопозиция», здесь физически нельзя.

Ничего секретного тут нет — ни токена бота, ни координат клиники, ни данных
сотрудников. Только HTML и скрипт, который спрашивает у телефона его место.

Исходник: `index.html`, один файл, без сборки и зависимостей.
